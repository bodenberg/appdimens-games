# Custom scaling strategies (C / C++)

`appdimens_custom.h` is a portable C99 single header (C++ compatible) that ports `appdimens-dynamic`
**library-custom**: the same JSON document, text-formula language, built-ins and presets as Android,
iOS, Flutter, React Native, Web, .NET, KMP, Python and Games. `tests/test_custom.c` reproduces the
shared 540-case fixture generated by the Kotlin reference engine.

```c
#define ADC_IMPLEMENTATION            /* in exactly one .c/.cpp file */
#include "appdimens/appdimens_custom.h"

char err[256];
if (!adc_load_json(json_text, err, sizeof err))      /* registers ids, applies "default" */
    fprintf(stderr, "custom strategies: %s\n", err);  /* strict + atomic: nothing registered */

const adc_strategy *brand = adc_get("brand");          /* registered → built-in → preset */
float pad = adc_dp(brand, metrics, 16);                /* dp; adc_px → px */
float txt = adc_sp(adc_get("readableText"), metrics, 14); /* text dp, font-scale policy applied */

adc_strategy *hud = adc_formula("base * pow(sw / 360, 0.8)", err, sizeof err); /* shared per text */

static double product(const adc_screen *s, void *user) {  /* factor from code */
    double f = s->width / 360.0; (void)user; return f < 0.85 ? 0.85 : f > 1.8 ? 1.8 : f;
}
adc_register(adc_custom_factor("product", product, NULL));
```

`metrics` is the snapshot from `adg_acquire()` (or your own `adg_metrics_from_surface`). In REFERENCE mode plain `adc_dp` values are final px at the current resolution, exactly like the built-in tokens. Kotlin, Unity/.NET C# and Godot (C#) use the `appdimens-games-custom` module instead; Unreal gets this header in `ThirdParty/appdimens`.
`adc_dp/adc_sp/adc_px/adc_factor` memoize the last snapshot per strategy (one UI/game thread); for other
threads call `adc_resolve(strategy, &screen, &resolved)` into your own `adc_resolved` and then
`adc_scale`, `adc_scale_sp_dp`, `adc_scale_sp_units` (no allocation, thread-safe).
`adc_explain` writes the factor, axis, reference, rules and clamps on one line.

JSON document (`{"version": 1, "default": …, "strategies": [...]}`): `extends` (built-in, preset or
another id), `reference`, `axis` (`smallestWidth|width|height|min|max|diagonal|perimeter`), `curve`
(`linear|power|logarithmic|interpolated|constant|breakpoints|expression`), `multiplier`, `clamp`,
`valueClamp`, `aspectRatio`, `sensitivity`, `fontScale` (`follow|ignore|{max}`), `ignoreMultiWindow`,
`formula`, `rules` (`when: {device, orientation, smallestWidth/width/height/aspectRatio {min,max},
multiWindow}`, `set`). Built-ins: `scaled power logarithmic interpolated diagonal perimeter fixed`;
presets: `tabletFriendly compactFirst tvSafe wearable gameHud readableText`.

Notes: needs floating point and libm (`AD_FIXED_POINT` builds keep the built-in strategies only);
memory goes through `ADC_MALLOC` / `ADC_FREE` (default `malloc` / `free`). Full language and format
reference: [appdimens hub — DOCS/CUSTOM.md](https://github.com/bodenberg/appdimens/blob/main/DOCS/CUSTOM.md).
